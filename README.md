## DLL-injector-manual-in-c

## SOBRE O PROJETO

    Este é mais um projeto de estudos onde o objetivo principal é a injeção de uma Dll em um processo. Os unicos fins deste projeto são apenas para estudo nenhuma vontade maliciosa foi pensada além de aprendizado

## O QUE É UM DLL INJECTOR

        fundamentalmente um DLL Injector é um utilitário que força um processo legítimo em execução a carregar uma biblioteca dinâmica (arquivo .dll) de terceiros na memória dele.

## COMO RODAR?

    Primeiro crie um arqui .o do arquivo meuinjector.c
    Depois um .exe deste mesmo arquivo
    E ai rode este codigo: "gcc -shared meuinjector.c -o output/meuinjector.dll"
